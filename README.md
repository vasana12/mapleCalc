# 🍁 Mapulator — Drop Estimation & Hunt Time Predictor for MapleStory

> A GUI-driven productivity tool for power-grinders and probabilistic optimizers.

Mapulator estimates how long it will take you to acquire rare items in **MapleStory** using a statistical model combined with real-world hunting speed.

---

## ✨ Features

- 📊 Drop probability calculator with 50–99% confidence levels
- ⏱ Real-time hunt rate measurement via EXP delta tracking
- 🧠 Smart prediction of required kill counts and time
- 💾 Persistent monster/item/drop configurations
- 🖱 Intuitive PyQt5-based GUI

---

## 🔧 Installation

### Requirements

- Python ≥ 3.7
- PyQt5

### Install dependencies

```bash
pip install PyQt5
```

### 📦 Build as Executable (Windows)
```bash
pyinstaller --onefile --windowed --icon=./ico/maple.ico --name=Mapulator main.py
```
