# 📘 사용자 매뉴얼 — Mapulator v1.0

Mapulator는 **메이플스토리 파밍 효율 극대화**를 위해 고안된 GUI 툴로,  
1) 통계적 드랍 예측  
2) 실시간 사냥 속도 측정 기반 시간 예측  
두 가지 핵심 기능을 제공합니다.

---

## 🧩 주요 기능

### 1. 드랍 예측
- 목표 아이템 개수 달성을 위해 필요한 몬스터 킬 수 계산  
- 50%, 60%, 70%, 80%, 90%, 99% 신뢰도 옵션 지원  

### 2. 시간 예측
- 시작·끝 경험치 차이로 킬/분 속도를 측정  
- 측정된 사냥 속도로 목표 달성 예상 소요 시간 계산  

### 3. 환경 설정 관리
- 몬스터 이름, 아이템 이름, 드랍 확률(%, 소수) 및 킬당 경험치 저장  
- `drop_configs.json`에 자동 저장·불러오기  

---

## 🎛 탭별 사용법

### 1️⃣ 설정 저장 탭
1. **몬스터 이름**, **아이템 이름**, **드랍 확률**(`50%` 또는 `0.5`), **킬당 경험치** 입력  
2. `Enter` 키 또는 **💾 저장** 버튼 클릭  
3. `drop_configs.json`에 설정이 추가되며, 이후 탭에서 바로 선택 가능  

### 2️⃣ 드랍 예측 탭
1. **설정 선택** 드롭다운에서 원하는 몹·아이템 조합 선택  
2. **목표 개수** 입력 (정수) → `Enter` 키 또는 **🔍 예측** 버튼 클릭  
3. 50%, 60%, 70%, 80%, 90%, 99% 확률별 최소 킬 수를 한눈에 확인  

### 3️⃣ 시간 측정 탭
1. **설정 선택** / **목표 개수** 입력 (비워두면 `1` 기본)  
2. **시작 경험치** 입력 → **▶ 측정 시작** 클릭  
   - 버튼이 “■ 측정 중지”로 토글  
   - 실시간 **남은 시간**, **시작/종료 시각** 표시  
3. 타이머 종료(자동 또는 중지 클릭) 후 **끝 경험치** 입력  
4. **⏳ 예측 실행** 클릭 →  
   - 필요 킬 수(90% 기준)  
   - 킬 속도(킬/분)  
   - 예상 소요 시간 (60분 이상 시 “X시간 Y분” 포맷)
